# UrbanFlow

Projet de simulation et d'optimisation de déplacements urbains développé en Python.

## Technologies

* Python
* Pygame
* NetworkX

## État actuel

Le projet contient actuellement :

* génération d'une grille de sommets ;
* génération d'un graphe ;
* génération d'un arbre couvrant aléatoire ;
* affichage graphique avec Pygame ;
* fenêtre redimensionnable ;
* classe Sommet.

## Lancement

Installer les dépendances :


pip install pygame networkx


Puis lancer :


python main.py


## Prochaines étapes

* intégrer les agents ;
* gérer les déplacements sur le graphe ;
* ajouter les routes et leurs caractéristiques ;
* introduire les incidents et les contraintes ;
* comparer différents chemins ;
* intégrer des critères de temps, distance et impact environnemental.
